# Vincent Deriv Analyzer

A lightweight browser-based market analyzer for Deriv volatility indices.

## Features
- Connect to the Deriv WebSocket API
- Subscribe to a selected market
- Track the last digit from recent ticks
- Show recent digit history and frequency counts
- Display simple "match/differ" analysis output

## How to use
1. Open `index.html` in a browser.
2. Connect to Deriv using an optional token.
3. Select a market and start analysis.

## Notes
- This project is intended for educational and experimental analysis only.
- It does not guarantee predictive accuracy.
